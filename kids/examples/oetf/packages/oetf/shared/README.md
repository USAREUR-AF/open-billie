# OETF shared artifacts

This folder is the **single source of truth** for OETF. It holds no code, only language-neutral JSON. The TypeScript, Python and Rust implementations next to it all read these exact files, and none of them keeps a copy of its own.

```
shared/
├── schemas/        decode schemas: byte offsets, types, scales, enum labels
│   ├── header.json        16-byte frame header
│   ├── msg_1.json         Sensor Status
│   ├── msg_16.json        Track Report (8 track slots; generated by tools/gen-schemas.py)
│   └── _meta.schema.json  JSON Schema the decode schemas conform to
├── mappings/       mapping schemas: one file per (source message × target protocol)
│   └── OETF_msg_16/
│       ├── asterix-cat062.json
│       ├── cot.json
│       └── sapient.json
├── lookups/        label tables referenced by `lookup` conversions in the maps
└── conformance/    golden vectors every implementation must reproduce exactly
```

## Who reads what

| | `schemas/` | `mappings/` + `lookups/` | `conformance/` |
|---|---|---|---|
| **TypeScript** (`../typescript`) | `decoder` reads them at runtime | `mappings` exports their paths to a translator engine | `decoder` and `mappings` test suites |
| **Python** (`../python`) | read at runtime (`paths.py`) | executed by `billie_oetf.Mapper` | `tests/test_conformance.py` |
| **Rust** (`../rust`) | embedded at compile time by `build.rs` | embedded and executed by `Mapper::bundled()` | `tests/conformance.rs` |

The TypeScript, Python, and Rust implementations use this shared directory directly from the Open Billie repository. The language packages are private workspace components and are not published to GitHub Packages.

## Changing the format or a mapping

1. Edit the JSON here. For the Track Report layout, edit `tools/gen-schemas.py` and run `pnpm gen:schemas`.
2. Regenerate the conformance vectors using the TypeScript reference decoder and the mapping engine in the Open Billie workspace. The original generator depended on an external translator checkout and is not included in this standalone synthetic package.
3. Run `pnpm test:all`. TypeScript, Python and Rust must all pass against the vectors.
